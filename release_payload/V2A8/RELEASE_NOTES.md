# PostalBorkenMenu V2A8

First canonical stable release of **PostalBorkenMenu** for **POSTAL: Brain-Damaged**.

> **Borken is intentional** — a nod to *POSTAL: No Regerts*.

## Highlights

- Native IL2CPP developer-command bridge
- Reliable configurable hotkeys
- Persistent settings and keybinds
- **TimeScale** defaults to **0.5x**; clicking the same non-1.0 value again returns to **1.0x**
- **No Crosshair** hides only the visual reticle and preserves weapon aim
- **Give All Weapons** grants weapons without quest items
- Clean shutdown without the exit crash from earlier test builds
- Native developer commands remain intact; PostalBorkenMenu additions are separate entries

## Important

- **Remove `-debug` from the game's launch options**
- Requires a compatible **x64 ASI loader**, distributed separately
- No game EXE, `GameAssembly.dll`, or `UnityPlayer.dll` is patched on disk
